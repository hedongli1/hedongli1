## 二、真实 bug 修复记录（最有价值的"可证伪"素材）

1. **`npm test` 进程挂死**
   - 根因：`index.js` 在 `NODE_ENV !== 'test'` 时顶层 `app.listen(3100)`，测试只关自己 `listen(0)` 的服务，3100 那台没人关 → 事件循环永不退出
   - 修复：test 脚本显式 `NODE_ENV=test node --test`

2. **lockfile 绑定内网镜像，CI 403**
   - 根因：全局 `~/.npmrc` 指向内网源，lockfile 的 `resolved` 字段全写内网 URL，GitHub runner 访问不到
   - 修复：`npm install --registry=https://registry.npmjs.org/` 重新生成

这两条都已写入博客文章，可复现、可验证。
