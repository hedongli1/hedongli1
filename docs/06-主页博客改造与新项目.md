## 二、博客视觉升级（hedongli1.github.io）

### 1. 背景从「静态」到「动态」的六层叠加

原博客背景只有一层金色星云 + 粒子连线，看久了偏「平」。本轮在**不推翻原设计**的前提下，逐层叠加：

```
第 1 层  星云底图（AI 生成，黑金配色，裁水印）
第 2 层  星云渐变（原有柔光，保留）
第 3 层  星点网格（细点阵，向四周渐隐）
第 4 层  粒子连线（原有金色粒子，保留）
第 5 层  轨道环（金色光点绕椭圆轨道带光晕转）
第 6 层  暗角遮罩（四周压暗，聚焦中央）
```

### 2. 星空「活」起来的三类新元素

针对「星空单调」（都是同一种金色小点）的问题，新增：

- **闪烁星星**：大小不一的星点呼吸明灭
- **金色尘埃**：极小光点缓慢上浮，制造纵深
- **星芒亮点**：带十字光芒的大星做视觉焦点

### 3. 踩坑记录

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| 特效太淡 | 透明度 0.045、光点 1.5px，深色底上肉眼不可见 | 透明度翻倍、光点加到 3px+ |
| AI 图带水印 | 右下角「AI生成」小字 | PIL 裁掉底部一条再压缩 |
| PNG 体积爆炸 | 4MB/张 × 4 张 | 转 JPG 压到 250–560KB |

## 四、新项目：fin-intel-agent

**仓库**：https://github.com/hedongli1/fin-intel-agent （公开 · MIT）

金融/股票领域定时监控 Agent（纯后端 Python），核心链路：

```
成交额/涨幅/换手率/量比/总市值 五榜各取前 20 名
  → 并集去重 → 动态监控池（上限 100 只）
  → 五维深采集（行情/财务/新闻/研报/板块）
  → 汇总 Markdown 报告 → 推送飞书群机器人
```

### 技术要点

- **单一数据源 akshare**：零 API key，开箱即用
- **异常隔离**：单只股票失败不影响整轮
- **分片推送**：超长报告防飞书限流
- **非交易日跳过**：APScheduler 定时，周末自动跳过

### 推送前清理（安全）

- 删除 README 顶部 `AIGC` 溯源段
- `.gitignore` 排除 `data/`（运行时日志/报告不公开）
- `.env`（飞书 webhook）未推送
